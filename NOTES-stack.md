# Spiti Circuit site — stack notes (T0.0)

How `spiti/` is built. Recorded before working through `spiti/todo.md`, and updated after it.
Paths in the todo were guesses; the real ones are below.

## Surfaces

| URL | Source | How it is made |
|---|---|---|
| `/spiti/` | `spiti/index.html` | Hand-written static HTML, inline CSS. |
| `/spiti/book/` | `spiti/book/spiti-circuit-the-long-read.md` | Generated into `spiti/book/index.html` by `scripts/build_spiti_book.py`. |
| `/spiti/practical/` | `spiti/practical/practical.md` | Generated by the same build (`spiti_extras.build_practical`), sharing the book's CSS. Holds every `Practical` box, stop by stop (`#stops`); the book itself has none. |
| `/spiti/preparation/` | `spiti/preparation/index.html` + `support.js` + `_ds/` | Exported from a design tool. Client-side templating (`<x-dc>`, `{{ … }}` bindings) hydrated by `support.js`, which loads React 18 from unpkg. Not generated here. Its header shows the route map and the altitude plot, both from `spiti/book/img/`. Has a `<noscript>` fallback so raw bindings never show without JavaScript. Packing and shopping state live in `localStorage` (`spiti-pack-v1`, `spiti-shop-v1`) with reset buttons. |
| `/spiti/map/` | `spiti/map/index.html` | Standalone Leaflet page (from `spiti-route-map.zip`); data inline. Tiles are online-only. |

## Generator

No SSG. Plain files plus Python:

- `scripts/build_spiti_book.py` — Python 3 + **Python-Markdown** (`tables`, `smarty`, `sane_lists`). HTML template, CSS and
  JS are string constants in the script (`TEMPLATE`, `SW_TEMPLATE`); `%%TOKENS%%` are replaced with `str.replace`.
  Writes the book, `search-index.json`, the practical page, `content/unverified.md`, `content/shot-list.md` and
  `spiti/sw.js`. **Fails the build** on broken `#links`, duplicate ids, image/map anchors that match nothing, unknown
  sections in `content/today.json`, and "Chapter N"/"Interlude N" references that point at a missing section or,
  by a word-overlap check, clearly at the wrong one (accept deliberate ones in `content/xref-allow.txt`).
- `scripts/spiti_extras.py` — search records, glossary popovers, A–Z index, today, practical page, reports.
- `scripts/commons_image.py` — fetch Wikimedia images into `spiti/book/img/` and `spiti/book/images.json`.
- `scripts/build_chapter_maps.py` — chapter maps drawn from OpenStreetMap extracts (`--fetch` once, then draw).
  Writes `spiti/book/img/map-*.svg`, `spiti/book/maps.json`, `content/unverified-maps.json`. Not run in CI.
- `scripts/build_route_map.py` — the route map on the preparation page: user's SVG warped onto an OSM raster, plus the Kinnaur–Spiti
  boundary, the watershed note and the night-halt dates. Not run in CI.

## Book content

- **One markdown file**. `# …` = section (cover, `Chapter N · …`, `Interlude <Word> · …`, `Sidebar · …`, `Coda · …`,
  `Appendix X · …`). `## Contents` drives the sidebar groups.
- Boxes by heading prefix (`### Prefix: title`): interpretive — `In the rock`, `The other story`, `Who came through
  here`; actionable — `Practical` (blue, used only on the practical page), `Caution` (amber), `Respect` (green);
  after the trip — `Field notes`.
  A `Source: …` / `Checked: …` paragraph is the stamp at the foot of a box.
- `TODO(verify)` anywhere renders as a "to verify" chip and is listed in `content/unverified.md`.
- `… section · Title` and `PART ONE · …` headings get a small label.
- Heading ids: section id (`ch-7`, `interlude-3`, `sidebar-…`, `appendix-b`, `index`) + slug of the heading.

## Figures

- `spiti/book/images.json` — photos (`anchor` = chapter title or heading; optional `after` = bold item → thumbnail or grid).
- `spiti/book/maps.json` — chapter maps, inlined as SVG (inherit page colours and dark/night mode).
- `spiti/book/figures.json` — the hand-drawn diagrams in `spiti/book/img/figures/`, used as `<img>` (they carry their own dark mode).
- Gallery-only photos are 560 px wide; others up to 1200 px. `width`/`height` and `loading="lazy"` are always set.

## Navigation, search, reading

- Sidebar/drawer from the section list; scroll-spy; per-chapter progress bar; "continue reading" (`spiti-book-pos`).
- Search: `spiti/book/search-index.json` (one record per section/heading) + vendored MiniSearch 7.2.0
  (`spiti/book/vendor/`), loaded on first open. Aliases in `spiti/book/search-aliases.json` (edit freely).
  Opens with the magnifier, `/` or Ctrl/Cmd+K.
- Glossary: first use of each Appendix D word per chapter gets a popover.
- Index: A–Z from `content/index-terms.yml`.
- Today: `content/today.json` maps trip dates to sections (`?today=YYYY-MM-DD` previews).
- Modes: light / dark / night (dim, warm) and three text sizes, stored in `localStorage` (`spiti-theme`, `spiti-size`).

## Offline (service worker)

- `spiti/sw.js`, **generated**. Scope `/spiti/`. Precache = every file under `spiti/` except markdown, zips, `sw.js` and
  build-only JSON, as `[url, bytes, sha256]`; `VERSION` is a hash of all of them.
- Install copies unchanged files from the previous version's cache (matched by hash), downloads the rest six at a time,
  and posts progress; `spiti/pwa.js` shows it (`data-pwa-status`: files and MB, or a failure).
- Same-origin: cache-first. Third-party: only Google Fonts and unpkg are cached; map tiles pass through.
- `pwa.js` also: Update toast, Check for updates, install prompt, and marks links to other sites "needs signal" when offline.
- Current install: ~207 files, ~19.6 MB.

## Content registries

- `content/volatile.yml` — practical claims that go stale, with `verified` and `expires`; expired ones warn at build.
- `content/unverified.md` — generated checklist (TODO(verify), approximate map features, never-verified claims).
- `content/shot-list.md` — generated: current photos per chapter and what to shoot instead.

## Build and deploy

- Local: `make spiti-book` (part of `make all`).
- CI: `.github/workflows/deploy.yml` on push to `main` → apt installs TeX/LaTeXML + `python3-markdown` → `make` → copies
  `index.html assets .nojekyll spiti build` into `_site` → GitHub Pages. Everything under `spiti/` is published,
  including any stray files there (zips, drafts, `todo.md`).
